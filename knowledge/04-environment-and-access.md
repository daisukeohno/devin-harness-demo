## ローカル / Devin VM

- パッケージ管理は `uv`。`pip` は使わない。
- Python は 3.10 以上。`uv sync --extra dev` で開発依存まで入る。
- テストは `uv run pytest`、lint は `uv run ruff check .`。
- サンプルデータはリポジトリに同梱されているので、外部接続なしで全テストが通る。

## 実データを扱う場合（このリポジトリでは未接続）

- 実データはオブジェクトストレージ上にあり、読み取り用の資格情報は Devin の Secrets に登録して参照する。値をコードやノートに書かない。
- 社外に出せないデータを扱う場合は、顧客インフラ上でセッションを動かす構成（Outposts）を検討する。この場合、推論はクラウド、コマンド実行とファイル操作は顧客側マシンで行われる。
- 実機やベンチ装置に接続する検証は、装置の近くにワーカーを置く前提。ネットワークとライセンスの確認が先。

## CI

- GitHub Actions で lint と pytest を実行する（`.github/workflows/ci.yml`）。
- CI が落ちたら、ログを確認してから修正する。再実行で通ることを期待しない。
