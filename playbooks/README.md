# Playbook 登録用テンプレート

Playbook は Devin の Web アプリ側で管理し、セッション開始時に添付します。
このディレクトリの Markdown はその貼り付け元です。

## 登録方法

1. Web アプリで Playbooks を開き、New playbook
2. ファイル名に対応するタイトルを入れ、本文を貼り付ける
3. 保存後、セッション開始画面で `@playbook:` から添付する

セッション内の Devin に「playbooks/ 以下を Playbook として登録して」と頼むこともできます（作成には承認が入ります）。

## Skills との違い（デモで説明するポイント）

| | Skills | Playbooks |
|---|---|---|
| 置き場所 | リポジトリ内の `SKILL.md`。コードと一緒にバージョン管理される | Web アプリ。UI で管理する |
| 起動 | Devin が自動で見つけて使う。`@skills:<name>` で明示指定も可能 | セッション開始時に人が添付する |
| 範囲 | リポジトリ単位 | 組織横断。どのリポジトリのセッションにも付けられる |
| 向いている内容 | テスト手順、デプロイ手順、そのリポジトリ固有の作法 | 繰り返す依頼のテンプレート、分析の進め方、定例作業 |
