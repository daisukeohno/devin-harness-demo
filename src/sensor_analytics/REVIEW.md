# REVIEW.md（`src/sensor_analytics/` 配下のみ）

ルートの `REVIEW.md` に加えて、解析コードにはこの観点も適用する。
Devin Review は `**/REVIEW.md` を拾うので、ディレクトリ単位で観点を上書き・追加できる。

- 統計量を返す関数は、母数（`n_samples`）と除外数（`n_dropped`）を必ず返す。返していない変更は指摘する。
- 異常検知のウィンドウ幅より短い系列を渡されたときの挙動が定義されているか（例外か、空結果か）。
- `analysis.py` は I/O を持たない。ファイル読み込みや HTTP 呼び出しが混ざったら指摘する。
- 新しい解析関数には、少なくとも「正常系」「全欠損」「サンプル数不足」の 3 ケースのテストを求める。
